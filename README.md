## 📝 Description

This Weather App allows users to search for the weather of any city in the world in real-time. It retrieves live weather data such as temperature, humidity, wind speed, and overall weather condition using the OpenWeather API. The interface is designed to be simple, fast, and responsive so users can quickly get weather updates on any device.
